# 🎨 CookCart AI Design System

> Design Language for Blinkit Personal Chef
> Version 1.0

---

# Design Philosophy

CookCart AI transforms Blinkit from a grocery marketplace into an AI-powered cooking assistant.

The design should feel:

- Premium
- Modern
- Clean
- Friendly
- Fast
- Food-first
- AI-assisted
- Minimal but visually rich

Users should immediately understand:

> "Search any dish → AI prepares the recipe → Get exact ingredients → Cook confidently."

The experience should reduce friction and encourage confidence while cooking.

# Overall Feeling

The interface should feel like

> Apple meets Blinkit meets a Michelin cookbook.

Users should instantly feel

"I can actually cook this."

The interface should build confidence, reduce decision fatigue, and make grocery shopping feel like cooking with a personal AI chef.

# Design Principles

✓ Food-first visuals

✓ Premium simplicity

✓ Generous white space

✓ Soft rounded cards

✓ Fresh green accents

✓ High readability

✓ Minimal distractions

✓ Delightful micro-interactions

✓ AI feels helpful, never overwhelming

✓ Every screen should communicate one clear action
